# Portfolio de Ian / NNytro

Sitio estático del portfolio personal. GitHub Pages se publica automáticamente al subir cambios a `main`.

## Publicar

1. Crear un repositorio en GitHub y subir el contenido de esta carpeta a la rama `main`.
2. En **Settings → Pages**, elegir **GitHub Actions** como fuente.
3. El workflow `.github/workflows/pages.yml` hará el despliegue en cada push.
